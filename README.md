# Instituto Projeto Família e Vulnerável — Programa Recomeço

Site institucional de apresentação de um projeto escolar de proposta legislativa para Curitiba/PR.

## Arquivos

- `index.html`: conteúdo e estrutura do site.
- `style.css`: identidade visual responsiva (amarelo manteiga e azul bebê).
- `script.js`: menu mobile, busca dos artigos e controles de expandir/recolher.

## Como visualizar

1. Baixe e extraia a pasta.
2. Abra `index.html` no navegador.

Não é necessário instalar programas nem executar comandos.

## Como publicar no GitHub Pages

1. Entre no GitHub e crie um repositório público. Exemplo: `projeto-familia-vulneravel`.
2. Envie os três arquivos (`index.html`, `style.css` e `script.js`) para a raiz do repositório.
3. No repositório, abra **Settings** → **Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Selecione a branch `main` e a pasta `/ (root)`, depois clique em **Save**.
6. Aguarde a publicação. O GitHub mostrará o endereço do site na mesma tela.

## Observações importantes

- O texto foi organizado a partir do conteúdo enviado pelo grupo, com correções de ortografia, pontuação e formatação.
- A numeração foi ajustada conforme a orientação recebida: Art. 9º (parcerias), Art. 10º (acompanhamento e fiscalização), Art. 11º (orçamento) e Art. 12º (proteção de dados).
- A página identifica o conteúdo como projeto acadêmico e não como canal oficial da Prefeitura.
- Os dados e referências legais devem ser conferidos nas fontes originais. A organização do site não equivale a revisão jurídica da proposta.
- O site usa Google Fonts quando há conexão com a internet; se não houver, usa fontes alternativas instaladas no dispositivo.
